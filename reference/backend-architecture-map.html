Backend architecture map

The Worker is the outer runtime. Hono is the HTTP application inside it.

Cloudflare Worker
Receives HTTP, queue, and scheduled events.
↓ HTTP requests use fetch: app.fetch
Hono app
Contains middleware, routers, routes, and error handlers.
↓ matching route
Route handler
Validates input and coordinates authentication, metering, services, and storage.

Terms

TermMeaning here
WorkerThe deployed Cloudflare program containing all event handlers.
Hono appThe HTTP router created with new Hono<App>().
MiddlewareA function that runs around matching handlers and may continue with next().
Route handlerThe endpoint-specific function such as the search or project handler.
ServiceReusable business or integration logic called by a route.
ContextThe per-request Hono object containing the request, environment, principal, and response helpers.
