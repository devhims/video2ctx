# Issue tracker: Local Markdown

Issues and PRDs for this repository live as Markdown files in `.scratch/` during development.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`
- The PRD is `.scratch/<feature-slug>/PRD.md`
- Implementation issues are `.scratch/<feature-slug>/issues/<NN>-<slug>.md`
- Triage state is a `Status:` line near the top of each issue
- Comments append under a `## Comments` heading

When a skill publishes work, it creates the corresponding file under `.scratch/<feature-slug>/`.
