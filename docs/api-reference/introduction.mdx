The reference below is generated from the same OpenAPI 3.1 document served by the platform. It includes consumer-facing provider data, research, projects, exports, monitoring, notifications, trends, and usage operations.

Use `https://api.video2ctx.dev` as the server. The video2ctx skills authenticate with a device-authorized CLI session; unattended integrations can authenticate with a personal API key:

```http
Authorization: Bearer aty_…
```

<Warning>
  The interactive playground sends real requests to the hosted API. Fresh data and composite operations can spend credits or create account-owned resources.
</Warning>

First-party application flows, callbacks, webhooks, administration, and destructive account operations are documented separately without interactive controls under [Platform internals](/internals/overview).
