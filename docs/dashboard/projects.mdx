title: "Projects and saved research"
description: "Keep related sources and evidence together."
---

Projects organize sources you want to revisit. Saving an inspected source keeps the requested data in your account and groups it with related sources. Saving and reopening retained data do not use credits or start another import.

<Steps>
  <Step title="Inspect a source">Search, or open a video or playlist, from Sources. Select **Channel info** before opening a video to keep its creator profile.</Step>
  <Step title="Save it">Choose **Save to project**. If you have no projects, the dashboard creates a research inbox.</Step>
  <Step title="Review the project">Open Projects to see saved items and return to the underlying source.</Step>
</Steps>

Projects are private to the signed-in account. API keys created by that account can access the same projects and credit balance.

## Reopening saved items

Opening a saved project item reads storage without a YouTube request or credit charge. **Save to project** and **Save playlist** retain the version you viewed, including every comments page you loaded and successfully saved. Items stay available after they leave Recent sources.

Older items can recover data already stored for your project. Recovered content is marked because it may be newer than the version originally viewed. If some data is missing, the available content stays visible. **Reload saved data** retries storage at no cost. If nothing is available, the item shows an unavailable message and a free retry. There is no paid recovery action in a saved project view.

A saved search or playlist retains its result list. Opening a listed video uses its saved project item when available. A video that was never inspected and saved has no retained transcript or comments. New inspections and requests for new data are separate actions in Sources and can use credits.

Saving the same video, playlist or channel again, including through **Add sources**, updates the existing whole-source item instead of adding a duplicate. Saved moments stay separate. Saving does not import playlist or channel members automatically.
