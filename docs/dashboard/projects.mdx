Projects organize sources you want to revisit. Saving an inspected source stores its identity and selected content in your account, then starts the import path used by research tools.

<Steps>
  <Step title="Inspect a source">Open a video, channel, or playlist from Sources.</Step>
  <Step title="Save it">Choose **Save to project**. If you have no projects, the dashboard creates a research inbox.</Step>
  <Step title="Review the project">Open Projects to see saved items and return to the underlying source.</Step>
</Steps>

Projects are private to the signed-in account. API keys created by that account can access the same projects and credit balance.

<Note>
  Imports and AI research jobs can finish asynchronously. The API exposes job state even when the dashboard does not show every intermediate step.
</Note>

## Reopening saved items

Opening a saved project item restores its stored data without a YouTube request or credit charge. **Save to project** and **Save playlist** keep the saved content with the project item, so later opens show exactly the version you saved. An older item opens from data already stored for your project when that data is still available. Such recovered data is the newest stored copy, so it may be newer than the version you originally saw, and it is marked as recovered. If an optional dataset, such as comments, was not kept, the rest stays visible and that dataset offers a credit-labeled fetch. Opening an item never turns on automatic saving into the project.

In the rare case that nothing for an item is stored any more, Sources shows a credit notice and waits for **Inspect using credits**. You can cancel or go back without requesting data. That inspection appears in Recent sources; choose **Save to project** afterwards to keep it with the item. Refreshing data, loading comments and retrying a failed dataset also use credits and say so.

Saving the same video, playlist or channel again, including from **Add sources** in a project that already has it, returns the existing item instead of adding a duplicate. Saved moments stay separate items. The standalone **Save to project** and **Save playlist** workflow continues to start the existing research import; adding sources from within a project does not start one, as before.
