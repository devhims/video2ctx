---
title: "Sources, videos, and playlists"
description: "Use one input for search terms, video URLs, and playlist URLs."
---

Sources is designed around one question: what video context do you need right now?

| Input | Result |
| --- | --- |
| Title or topic | Searches YouTube and returns videos to review |
| Video URL | Opens the video and fetches the selected datasets |
| Playlist URL | Opens playlist details and its video index |

Opening a playlist does not automatically fetch transcripts or comments for every item. Open an individual video when you want its deeper data; this keeps requests deliberate and credit usage predictable.

<Tip>
  Search accepts human-readable terms. You do not need to find a YouTube ID before using the dashboard.
</Tip>

When an upstream source is unavailable, existing results remain visible and the dashboard identifies which requested dataset could not be loaded.
