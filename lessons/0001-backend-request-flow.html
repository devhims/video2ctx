Follow one backend request

Goal: trace a request without confusing the Cloudflare Worker, Hono app, middleware, and endpoint handler.

Use the building analogy

  • Cloudflare Worker: the building receiving several kinds of deliveries.
  • Hono app: the HTTP reception desk and directory.
  • Middleware: checkpoints in the hallway.
  • Route handler: the department that does the requested job.
  • Services and storage: the tools and filing systems used by that department.
Browser or API client sends GET /v1/videos/:id
↓
Cloudflare chooses the Worker's fetch handler
↓ fetch: app.fetch
Hono runs request context, CORS, and authentication middleware
↓ route is classified as a data route
The video route validates the ID and reserves credits
↓
The YouTube service uses D1 cache or the upstream provider
↓
Credits settle, JSON returns, and the outer middleware writes the access log

The key distinction

app is only the HTTP portion. The default Worker export wraps it because the same deployed program also has queue and scheduled entry points.

Retrieval check: If a cron trigger fires, does it enter Hono middleware? Answer before reading on.

Answer: No. Cloudflare calls scheduled() directly. Only HTTP requests enter app.fetch() and the Hono chain.
