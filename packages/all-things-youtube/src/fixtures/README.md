# Storyboard image fixtures

The three 16×12 solid-color WebP images were generated with Sharp 0.35.3, with
RGB `(200, 50, 90)`. `lossy` uses default WebP encoding, `lossless` sets
`lossless: true`, and `alpha` uses lossy RGBA encoding with alpha 0.5.
They exercise VP8, VP8L, and VP8X/ALPH containers without external media.
They are test inputs only and are excluded from the npm package.
